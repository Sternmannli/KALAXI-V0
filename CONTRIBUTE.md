# Offer a Seed to Kalaxi

Kalaxi is a living metabolism.  
If something in you resonates — an observation, a tension, a pattern, a question, or even a quiet “this feels off” — you can offer it.

You don’t need to be certain.  
You don’t need perfect language.  
Presence is enough.

---

## How to Offer a Seed (Two Easy Ways)

### Way 1: Directly in THRESHOLD.md

1. Copy the template below.
2. Open the file `THRESHOLD.md` in this repository.
3. Paste your seed near the top.
4. Commit the change.

### Way 2: Open a GitHub Issue (Easiest for most people)

1. Go to the **Issues** tab of this repository.
2. Click **New issue**.
3. Write your seed in the description (you can use the template below).
4. Add the label **`seed`**.
5. Submit the issue.

We will review it and move well-formed seeds into `THRESHOLD.md` for you.
