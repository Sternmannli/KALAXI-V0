# About Kalaxi

Kalaxi is a constitutional framework for human dignity in computational systems.

## The Core Idea

Every system that interacts with humans makes ethical choices — whether it knows it or not. Kalaxi makes those choices explicit, testable, and enforceable.

The **Dignity Predicate** (`D = A x L x M`) is evaluated before every output, every action, every state transition. If dignity is violated, the system stops and opens a remedy path.

## The Four Tiers

- **Stone (Foundation)** — The covenants and rules that govern everything. Changing them requires years of consensus.
- **Weaver (Logic)** — Nine modules that do the work: memory, verification, synthesis, voice, pacing.
- **Honey (Wisdom)** — The growing knowledge: anomalies, proverbs, and patterns from donor contributions.
- **Hand (Interface)** — How donors interact: the Empty Hands Gesture, receipts, and the ledger.

## The Five Pillars

Kalaxi understands human expression through five lenses: Proverbs, Humour, Absurdity, Obsession, and Love. Each has a dedicated detector grounded in academic research.

## Principles

1. **Dignity First** — The system stops if dignity is violated
2. **Patterns, Not People** — Identity dissolves; wisdom remains
3. **Append-Only** — Nothing is ever deleted from the canon
4. **Steward Authority** — A human reviews and decides
5. **The Gap** — Room is always left for the river to move through
