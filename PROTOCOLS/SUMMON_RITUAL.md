## 1. Purpose

The Summon Ritual is a controlled scientific protocol for presenting KALAXI material to external AI models and collecting their responses. It measures how different models process dignity computation, witnessing, and institutional failure — under controlled conditions.

The ritual is not a conversation. It is a measurement. What returns from each model is data about that model's architecture, not opinion about the material.

## 3. Two Conditions (Mandatory for Types 1-3)

Every summon is sent TWICE to each model:

**FRESH** — Incognito/private window. No login. No memory. No prior conversation. The model encounters the input cold.

**MEMORY** — Logged in. With history. With whatever memory the model has from prior conversations with V-001.

The Perplexity pair proved this matters: same input, same model, same day — one engaged as research, one offered a crisis hotline. The ONLY variable was the context window. This is the core measurement.
