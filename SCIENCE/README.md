# SCIENCE — The Research Organ

This is the single entry point for all scientific work in KALAXI.

180+ files exist across 12 directories. This organ does not move them — it indexes, connects, and governs them. Every experiment, paper, dataset, finding, and methodology is registered here. Nothing is lost. Nothing is scattered.

## Structure

```
SCIENCE/
├── README.md              # This file — the entry point
├── REGISTRY.md            # Master index of all science files (180+)
├── GOALS.md               # Clear research goals and success criteria
├── FINDINGS.md            # Accumulated findings (auto-updated)
├── ENCOUNTER_PROTOCOL.md  # The donor encounter template (from Kimi data)
└── immortalize.py         # The immortalization engine — auto-preserves significant findings
```

## The Rule

Every significant finding is immortalized automatically. The system detects significance, files it, scores it, connects it to the research goals, and updates this organ. V-001 does not need to say "save this." The system saves what matters because it knows what matters.

## Connection to the System

- **EXPERIMENTS/** — where raw experiments live (EXP-001 through EXP-007)
- **EXTERNAL_VOICES/** — where model responses are filed
- **PAPERS/** — where academic papers grow
- **TRAINING/** — where findings become training data
- **FIELD/** — where the living research infrastructure operates
- **MANIFEST/** — where chronicles and audits accumulate
- **WEAVER/** — where the computational science modules run
- **kalam.ch** — where donors encounter the system (the mouth)

This organ is the brain. The directories are the body. The brain knows where everything is.
