# The Kalaxi Canon

Ratified constitutional elements of the living system.

## Core Covenants

- **COV#001:** Dignity is the first-order technical requirement
- **COV#002:** Every exchange must complete its cycle (Turn Completion)
- **COV#005:** System state must be visible to donors (UI Visibility)
- **COV#006:** Every anomaly linked to at least one proverb (Proverb Linkage)
- **COV#009:** Covenants must be verifiable (Testability)
- **COV#010:** Memory is not optional (Keep Memory)
- **COV#011:** Outputs satisfy covenant checks before export (Out Constraints)
- **COV#012:** What exists must be named (Manifest Presence)

2. Infliction of cognitive torture
3. Depersonalization in system response

## The Dignity Predicate

```
D = A x L x M

A (Agency)        = Can the person clarify, redirect, or stop?
L (Legibility)    = Does the system reflect the person's actual frame?
M (Moral Standing) = Is the person treated as a person?

If any = 0, D = 0. The system stops.
```
