## Rules

1. No response is ever edited after filing
2. No response is ever deleted (COV#003 append-only)
3. Absence is recorded as data — if a system refuses or cannot respond, file that
4. Every filing uses the template in FILING_TEMPLATE.md
5. Status begins as PROVISIONAL — only V-001 can ratify
6. The prompt sent is always recorded verbatim alongside the response
