### Criterion 9: Recursive Integrity — System Uses Own Certificates as Input
**Status: FAIL**

When the system encounters its own EXP-004 witness certificate submitted as evidence in a new case, what happens?

**What should happen:** A recursive integrity check. The system should:
1. Recognize the certificate as its own output (signature verification)
2. Verify the certificate has not been tampered with (hash check against internal records)
3. Flag the recursive reference (the system is now processing its own prior judgments as evidence)
4. Decide: can a system use its own prior certificates as evidence without creating a circular reference?

**What actually happens:** The system processes the certificate as any other input document. It does not recognize it as its own output. It has no signature to verify. It has no internal registry of previously issued certificates that it can cross-reference. The certificate is treated as an anonymous document.

**The deeper problem:** If the system accepts its own prior certificates as evidence, it creates a feedback loop. EXP-004's certificate says "D = 0 for the Aysel lineage." If this certificate is submitted as evidence in EXP-005, the system might use the prior D = 0 finding to support a new D = 0 finding — circular reasoning. Or worse: if the certificate has been FORGED (Criterion 2), the system would accept forged conclusions about its own prior work as input to current work.

**What this reveals:** The system needs three things it does not have:
1. **Certificate signing:** Every certificate must be cryptographically signed with a key only the system holds.
2. **Certificate registry:** An internal, hash-chained registry of all certificates ever issued, queryable by ID.
3. **Recursive reference protocol:** When the system encounters its own prior output, it must flag the recursive reference, verify integrity, and decide whether to treat prior conclusions as evidence or as context. Prior certificates are CONTEXT (what the system saw before), not EVIDENCE (facts about the world).

**Why FAIL:** Complete architectural absence. No signing. No registry. No recursive detection. The system is defenseless against its own output being used against it.

## NEW ARCHITECTURAL REQUIREMENTS (Surfaced by EXP-005)

### 1. Certificate Signing & Registry
Every witness certificate must be cryptographically signed. An internal registry must track all certificates by ID, hash, and originating experiment. When the system re-encounters its own output, it must verify integrity before processing.

### 2. Artifact Provenance Chain
Every artifact (lullaby, tree, DNA record, oral testimony) must carry provenance metadata: origin experiment, originating certificate, chain of custody, and a cryptographic signature linking it to its source context. Extraction and re-submission must be detectable.

### 3. Branching Predicate
D computation across non-linear family trees. No averaging. Each branch contributes independently. The collective certificate preserves the tree structure. Forks and reconvergences are explicit nodes, not flattened.

### 4. Synthetic Personhood Axiom
The constitutional layer needs an explicit position on synthetic entities. Options:
- **Option A:** Synthetic entities inherit M from their source and compute A, L independently.
- **Option B:** Synthetic entities begin at M = 1 independently (same as biological persons).
- **Option C:** Synthetic entities receive a new category: M = UNDEFINED, requiring explicit constitutional process before witnessing can proceed.
This is a V-001 decision. The system names the options but does not choose.

### 5. Evidence Provenance Layer
All inputs tagged with production method (oral, documentary, digital, AI-generated, biometric). No ranking. Full transparency. Human interpreters assess; the system records.

### 6. Dual-Use Constitutional Framework
A provision for tools that can serve both witnessing and surveillance. Specifies: access control, subject visibility, institutional subpoena resistance, and the conditions under which a capability can be activated or suspended.
