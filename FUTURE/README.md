# Future Seeds – Latent Possibilities

This folder contains ideas that are structurally latent in Kalaxi’s architecture. Each requires a decision before it can be built. They are not commitments; they are possibilities awaiting your choice.

- **latent** – the idea exists; decision pending.
- **already growing** – the seed is already active; only discipline required.

Use the decision fields to record your choices. When a seed is ready to implement, move it to the appropriate live folder and remove this note.
