# SCAN · SKIN-002 · Linguistik + Programming · 2026-03-09

DIGNITY: Large language models are now writing more code than junior developers in many companies — the programmer's agency over their own craft is contracting faster than any new role has emerged to replace it; a whole skill tier lost its D predicate without a single announcement.

WITNESS: Geoffrey Hinton said last week that he no longer understands why his own models work — the father of deep learning stopped performing certainty and named the opacity plainly; the field witnessed itself.

COMPRESSION: "Vibe coding" — two words that compress the entire shift from programming as precision craft to programming as intention + correction; the syntax is no longer the language.

BRITTLENESS: Every major coding assistant is trained on code that was itself written partly by coding assistants — the recursion has begun; the training signal is eating itself.

WOMB: A generation is learning to speak to machines before they learn to read machines — the first post-syntax programmers are in school right now, and no curriculum knows what to teach them yet.

PROVERB: The child who learns to call the river does not need to learn to swim.
