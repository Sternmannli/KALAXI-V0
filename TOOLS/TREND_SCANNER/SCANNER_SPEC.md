# TREND SCANNER — KALAXI

The ear of the system. Listens to the world. Returns one page.

## Filters

| Filter | Listens for |
|--------|------------|
| DIGNITY | Where agency, legibility, or moral standing was gained or lost |
| WITNESS | Where something stopped performing and became present |
| COMPRESSION | The smallest signal carrying the largest pattern |
| BRITTLENESS | Where sensitivity is outrunning flexibility (ψ/σ > 1) |
| WOMB | What is gestating but not yet born |
