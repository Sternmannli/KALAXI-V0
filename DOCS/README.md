## 🌊 Overview

Kalaxi is a dignity-first governance framework that embeds ethical constraints directly into computational infrastructure. Unlike conventional systems that optimize for efficiency or engagement, 
Kalaxi optimizes for **dignity preservation** — ensuring every interaction respects the agency, legibility, and moral standing of all participants.

This repository contains three core tools that implement the Kalaxi canon:

1. **`dignity_check.py`** — Evaluates text/actions against the Dignity Predicate (D = A × L × M)
2. **`gap004_mediator.py`** — Surfaces individual vs collective dignity conflicts without resolving them
3. **`canon_integrity.py`** — Scans canonical files for structural integrity issues
