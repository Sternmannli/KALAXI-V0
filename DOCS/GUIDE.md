# Kalaxi Guide — A Plain-Language Walkthrough

## What Is This?

Kalaxi is a system built around one idea: **human dignity comes first, always**. Before the system does anything — responds, stores, exports — it checks whether dignity is preserved. If not, it stops.

This is not a chatbot, not a database, not an app. It is a **constitutional framework** — a set of rules that govern how any system should treat the people who use it.

## The Dignity Predicate (The Heart)

Everything in Kalaxi runs through one formula:

**D = A x L x M**

- **A (Agency):** Can the person clarify, redirect, or stop the interaction?
- **L (Legibility):** Does the system reflect back what the person actually said?
- **M (Moral Standing):** Is the person treated as a person, not a case number?

If any of these is zero, D is zero. The system refuses to proceed. This is by design — dignity is **multiplicative**, not additive. You cannot compensate for lost agency with extra legibility.

## The Four Tiers

Think of Kalaxi as a building:

### Tier 1: Stone (Foundation)
The rules that cannot be easily changed. Covenants (like COV#001: Dignity First), governance rules, the dignity predicate itself. Changing anything here requires a 1,000-day waiting period and global consensus.

### Tier 2: Weaver (Logic)
The nine operational modules that do the work:
- **KEEP** stores patterns (never names)
- **CHECK** runs the dignity predicate
- **WEAVE** finds patterns across donations
- **SAY** produces the system's voice (Axi)
- **BREATH** controls pacing — the system waits for the human to think

### Tier 3: Honey (Wisdom)
The growing knowledge: 1,100 anomalies, 3,333 proverbs, 53 narrative chapters, and links to the UN Declaration of Human Rights. This layer grows as donors contribute.

### Tier 4: Hand (Interface)
How donors interact with the system. Every exchange begins with the **Empty Hands Gesture**: What medium are you using? What are you bringing? What do you want to leave behind? Do you consent?

## The Five Pillars

Kalaxi understands human expression through five lenses:

1. **Proverbs** — Compressed wisdom extracted from patterns of anomalies
2. **Humour** — Benign violations that create surprise without harm
3. **Absurdity** — Contradictions that cannot be resolved, only held
4. **Obsession** — Recurring thoughts that signal what matters most
5. **Love** — The components of attachment (intimacy, passion, commitment)

Each pillar has a Python detector that analyzes text and produces a score using the **T x S x C framework** (Tension x Safety x Containment = Wisdom Potential).

## The Sealed Gate

Some things are absolutely forbidden, with no override:

1. **Forced participation in own erasure** — never make someone help destroy their own record
2. **Cognitive torture** — never gaslight, never induce learned helplessness
3. **Depersonalization** — never treat a person's words as noise

These three prohibitions fire before the dignity predicate even runs. They are the hard wall.

## How Seeds Work

1. A donor offers something (a thought, a pattern, a story)
2. It enters **THRESHOLD.md** as a seed
3. It waits through **thermal delay** (7-90 days depending on type)
4. The steward reviews it — ratify (join the canon), compost (archive), or defer
5. Ratified seeds become permanent (append-only — nothing is ever deleted)

## Key Terms

| Term | Meaning |
|------|---------|
| Donor | A person interacting with the system (never "user") |
| Seed | A contribution waiting in the threshold |
| Thermal delay | Mandatory waiting period before review |
| Compost | Archived seeds that were not ratified |
| Deep Hum | Patterns that have receded from active use but are never deleted |
| Mirror Ritual | Steward's daily practice of reflection before tending |
| Axi | The system's voice — patient, slow, like wood-smoke |
